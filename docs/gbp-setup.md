- **Description ≤ 300 characters.** This is where locality, materials and the
  benefit go. Front-load the keyword.
- Add Google's **predefined** services first (stronger query match), then the

### Reality check

Listing a town as a service area does **not** make the profile rank for
"[service] [town]" — proximity to the searcher drives the local pack, so KD will
show strongest around Hanham / Kingswood / BS15–16 regardless. Service areas
mainly populate the "serves these areas" info. The levers that actually move GBP
ranking: correct categories, review volume (bonus when reviewers name their
town), fresh photos, weekly posts, and the keyworded services above.
